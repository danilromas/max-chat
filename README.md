# MAX Chat — чат для MAX на базе GREEN-API

Тестовое задание на должность «Фронтенд разработчик React» (GREEN-API).

Простой веб-интерфейс для отправки и получения текстовых сообщений в мессенджере **MAX** через [GREEN-API](https://green-api.com/max). Внешний вид — по мотивам [web.max.ru](https://web.max.ru/).

**Демо:** https://danilromas.github.io/max-chat/

## Возможности

1. Вход по учётным данным инстанса GREEN-API: `apiUrl`, `idInstance`, `apiTokenInstance` (данные проверяются методом `getStateInstance`)
2. Создание чата по номеру телефона получателя — номер превращается в `chatId` методом [`CheckAccount`](https://green-api.com/v3/docs/api/service/CheckAccount/) (в MAX писать можно только по `chatId`)
3. Отправка текстовых сообщений методом [`SendMessage`](https://green-api.com/v3/docs/api/sending/SendMessage/)
4. Получение сообщений через [HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/): `ReceiveNotification` (long polling) → обработка → `DeleteNotification`
5. Сообщения, отправленные с телефона, тоже появляются в чате; если пишет новый собеседник — чат добавляется в список автоматически
6. Учётные данные, чаты и история сохраняются в `localStorage`

## Стек

React 19 · TypeScript · Vite. Без UI-библиотек и стейт-менеджеров — задача требует минимального набора функций.

## Запуск локально

Нужен Node.js 20+.

```bash
git clone https://github.com/danilromas/max-chat.git
cd max-chat
npm install
npm run dev
```

Откройте http://localhost:5173.

Сборка для продакшена: `npm run build` (результат в `dist/`, можно выложить на любой статический хостинг).

## Как проверить

1. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com/), создайте инстанс для MAX на тарифе «Разработчик» (бесплатно) и авторизуйте его, отсканировав QR-код в приложении MAX.
2. Скопируйте из кабинета `apiUrl`, `idInstance` и `apiTokenInstance`.
3. Для получения сообщений через HTTP API в настройках инстанса должен быть **пустой `webhookUrl`** и включены уведомления о входящих (и, по желанию, исходящих) сообщениях.
4. Войдите в приложение, введите номер получателя (`79991234567`, `+7 999 123-45-67` и `8 999…` тоже подойдут) и нажмите «Создать».
5. Отправьте сообщение, ответьте на него из MAX на другом аккаунте — ответ появится в чате.

> Приложение работает и с инстансом WhatsApp: если метод `CheckAccount` недоступен, `chatId` формируется из номера (`79991234567@c.us`).

## Структура

```
src/
  api/greenApi.ts            — запросы к GREEN-API
  hooks/useNotifications.ts  — цикл получения уведомлений (receive → delete)
  hooks/useLocalStorage.ts   — состояние с сохранением в localStorage
  components/LoginForm.tsx   — вход по idInstance / apiTokenInstance
  components/NewChatForm.tsx — создание чата по номеру телефона
  components/Sidebar.tsx     — список чатов
  components/ChatWindow.tsx  — переписка и поле ввода
  App.tsx                    — состояние приложения и связка компонентов
```

## Решения и ограничения

- **Уведомления читаются последовательно:** следующее берётся только после `DeleteNotification` предыдущего — так GREEN-API рекомендует работать с очередью, иначе одно и то же уведомление придёт повторно.
- **Нет дублей своих сообщений:** отправленное сообщение сразу показывается в чате (оптимистичное обновление), а пришедшее следом уведомление `outgoingAPIMessageReceived` с тем же `idMessage` игнорируется.
- **Только текст:** уведомления с медиа, статусами и т.п. удаляются из очереди без отображения — по условию задания.
- История хранится локально в браузере: GREEN-API отдаёт через очередь только новые уведомления (очередь живёт 24 часа).
- Токен инстанса хранится в `localStorage` и используется прямо из браузера — для тестового задания это допустимо, в продакшене запросы стоило бы проксировать через свой бэкенд.
